# Mesto Project

## 🚀 Локальный запуск
-Запуск локального сервера npm run dev
-Сборка проекта npm run build
-Публикация на GitHub Pages npm run deploy
## 📋 Функциональность
- Работа с API
- Добавление/удаление карточек
- Лайки
- Статистика
- Валидация форм
